# Lector de hojas de composicion

Pagina estatica para extraer datos de PDFs de hojas de composicion y generar un Excel maestro.

## Uso

1. Abre la pagina.
2. Selecciona o arrastra los PDFs.
3. Pulsa `Extraer datos`.
4. Pulsa `Descargar Excel maestro`.

Los PDFs se procesan en el navegador y no se suben ni se guardan en ningun servidor.

## Despliegue

La pagina principal es `index.html`. La carpeta `vendor` contiene las librerias necesarias para leer PDFs y generar Excel sin depender de internet.
